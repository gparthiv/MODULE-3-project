# AI-Based Automotive Review and Customer Sentiment Analytics

A lightweight NLP mini-project for analyzing automotive reviews and identifying
sentiment for individual vehicle aspects.

## Architecture

Automotive Review
        ↓
Text Preprocessing
        ↓
DistilBERT Tokenizer
        ↓
Sentiment Classification
        ↓
Aspect Extraction
        ↓
Aspect-Level Sentiment
        ↓
JSON Result


## Technologies

- Python
- Flask
- Hugging Face Transformers
- DistilBERT
- PyTorch

## Supported Aspects

- Vehicle
- Engine
- Battery
- Mileage
- Safety
- Comfort
- Service
- Infotainment
- Price
